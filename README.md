# Quest Life

Quest Life is a gamified .NET MAUI life-management course project. See the [project plan, architecture, setup and current status](LifeManagementApp/README.md). The Unity files in this repository are an earlier prototype and are not the course's MAUI submission.

Work is tracked in the [GitHub issues](https://github.com/Muruseni/ClientSideSim/issues); the MAUI prototype still needs substantial work and has not been built or tested.
